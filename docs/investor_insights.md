# Investor lens — MindOrbit Learn (tight)

## One-line challenge

You ship **four** category stories at once (diagnostic adaptivity, graph UX, generative missions, UGC). Investors ask: **what single wedge earns the first habit and the first million users** before the rest matters?

---

## Core loop (pick one to own)

1. Diagnostic → map with weak nodes  
2. **One** mission path on the weakest cluster  
3. Visible “you moved” (node state, mini-check, or review cleared)

Defer or thin: full-graph exploration, community density, multi-subject parity, advanced insights—until this loop shows numbers.

---

## Beachhead (choose one lead for 12–18 months)

| Wedge        | Payer              | Edge                          | Risk                          |
| ------------ | ------------------ | ----------------------------- | ----------------------------- |
| SAT Math     | Parent / student   | High intent, maps to scores   | Crowded; need proof of lift   |
| Algebra      | Parent → school    | Standards + prereq graph      | Free incumbents; “next step” must win |
| Chemistry    | Parent             | Strong mission / misconception stories | Curriculum variance; content cost |

**GTM:** Schools (long cycle, rostering) vs B2C (CAC, content). Mixing both early often **doubles burn** without doubling proof—sequence one channel, then port evidence.

---

## Metrics (funnel → habit → money → proof)

| Stage        | Track |
| ------------ | ----- |
| Acquisition  | Channel traffic, signup %, CAC if paid |
| Diagnostic   | Started → **completed** (big drop-off tell) |
| Activation   | Map opened post-results; **first mission within 24h** |
| Habit        | WAU; missions / week; **% with 2nd–3rd mission in week one** |
| Retention    | D1 / D7 / D30 (D90 if exam); cohorts by source, subject, tier |
| Revenue      | Paywall view → checkout → paid; ARPU; churn |
| Learning     | Pre/post on **fixed** item set; time **weak → mastered** (definition fixed in appendix) |
| Economics    | AI + infra + support per heavy user; CAC vs LTV ranges |

**North star (early):** % of new users who complete **≥1 mission in first 7 days** (ties map, missions, and motivation better than raw DAU).

---

## Differentiation & moat (pressure-test)

- **vs Khan / free:** Habit switch needs **faster or better** outcome than watch + drill—not UX alone.  
- **vs IXL / schools:** They own distribution; B2C needs viral, SEO, or **wedge** so CAC works.  
- **vs ChatGPT:** Graph wins only if missions are **standards-tight** and progression is guaranteed—not generic generation.

**Moat (honest):** Today = clarity of next step + wedge content. Tomorrow = **calibrated items + outcome data** per node. “Network” (UGC, class maps) only after **density per node**.

**Paywall:** Post-diagnostic PRO can convert or **kill** the funnel—measure drop-off; don’t debate it without cohorts.

---

## Positioning

**Category:** Structured mastery + targeted practice; AI **inside** the graph, not a blank chat.

**One-liners:**  
Parent — *“Five minutes to see what’s missing; practice fixes that, not everything.”*  
Investor — *“Diagnostic-first graph; generative practice constrained by pedagogy and node telemetry.”*

**Risks to own in the room:** Scope vs runway; student data + UGC + AI compliance; “Cognitive Mastery Network” is memorable but **abstract** for parents and procurement—keep a plain acquisition line.

**Upside:** Diagnostic + map nails **anxiety reduction** (“I know what I don’t know”). Billing, feature gates, and analytics in-repo signal **iteration readiness**, not demo-only.

## Closing question (for you)

If you cut half the surface for a year: **which loop is sacred** (diagnostic → map → mission → mastery signal), and **which single metric** proves it—this week and this quarter?
